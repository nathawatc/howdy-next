# Security Policy

## Supported Versions

This project does not provide back-ported security fixes. Security fixes are released in the next
release version only, so please update to the latest release to receive them.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Report them privately through the GitHub Security Advisory form:

<https://github.com/nathawatc/howdy-next/security/advisories/new>
